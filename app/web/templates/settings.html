舊 Token 立即失效,請同步更新所有用戶端。
用戶端呼叫範例 
curl -X POST http://{{ host }}:{{ port }}/api/upload ^
     -H "X-Upload-Token: <token>" ^
     -F "file=@PC01_jsmith_20260101093000.mp4"

# PowerShell 5.1(無 -Form):
$h = @{ "X-Upload-Token" = "<token>" }
curl.exe -s -X POST "http://{{ host }}:{{ port }}/api/upload" -H "X-Upload-Token: <token>" -F "file=@C:\rec\PC01_jsmith_20260101093000.mp4"

檔名須為 <電腦名>_<帳號>_<YYYYMMDDHHMMSS>.mp4 才能解析電腦 / 帳號 / 錄影時間;舊版路徑 /upload 仍可用。 同名同大小視為重送(200);同名不同內容拒絕(409),不覆蓋既有錄影。

歸檔搬移(超過天數的錄影搬到網路路徑)

錄影時間超過指定天數的檔案,依排程從本機錄影資料夾搬移到網路路徑(複製 → 核對大小 → 刪本機), 釋放主機磁碟;搬走的錄影不再出現在總覽。目的端已有同名同大小者只刪本機;同名不同大小者略過不覆蓋。 搬移於保留清理之前執行,「錄影保留天數」請設 0 或大於歸檔天數。密碼留空 = 不變更。
填了網路路徑後,掃描器會一併索引該路徑的錄影,總覽多出「來源」篩選(本機 / 歸檔),歸檔錄影可直接播放與下載; 路徑離線時歸檔索引保留、卡片標示離線,不會被清掉。

立即搬移使用「已儲存」的設定;有修改請先儲存。
